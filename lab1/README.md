Что делает программа
`parent` считывает с консоли имя входного файла.\
Родитель открывает файл для чтения и создаёт `pipe`.\
После `fork()` дочерняя ветка через `dup2()` перенаправляет стандартный ввод на файл, стандартный вывод — в `pipe`, затем запускает отдельную программу `child` через `execve()`.\
`child` обрабатывает файл построчно. В каждой непустой строке первое целое число последовательно делится на каждое следующее; результат каждой строки выводится с новой строки.\
При делителе `0` дочерняя программа печатает сообщение об ошибке в stderr и завершает работу с кодом 2. Родитель получает EOF из канала, дожидается дочернего процесса через `waitpid()` и также завершается.\
Деление целочисленное, с округлением к нулю, как в C. Например, `100 3` даёт `33`.\
Сборка
```sh
make
```
Эквивалентная ручная сборка:
```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 parent.c -o parent
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 child.c -o child
```
Запуск
Запускайте из каталога, где лежат `parent` и `child`:
```sh
./parent
```
На приглашение введите имя файла, например `tests.txt`.
Можно указать путь к исполняемому файлу дочерней программы необязательным аргументом:
```sh
./parent ./child
```
Пример
Файл `tests.txt`:
```text
100 5 2
100 3
-100 2 3
7 -2
```
Ожидаемый вывод:
```text
10
33
-16
-3
```
Для проверки деления на ноль создайте файл `zero.txt`:
```text
20 2
10 0 3
100 2
```
Ожидаемый stdout содержит только результат первой строки `10`. При обработке второй строки `child` сообщает о делении на ноль в stderr и завершается; третья строка не обрабатывается.\
Основные системные вызовы\
`open()` — открыть входной файл.\
`pipe()` — создать неименованный канал.\
`fork()` — создать дочерний процесс.\
`dup2()` — перенаправить стандартный ввод и вывод дочернего процесса.\
`execve()` — запустить отдельную программу `child`.\
`read()` и `write()` — читать и передавать данные.\
`close()` — закрыть неиспользуемые файловые дескрипторы.\
`waitpid()` — дождаться завершения дочернего процесса.\
